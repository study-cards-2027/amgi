# 암기노트 v2.1

퀴즐렛 방식의 용어–정의 암기 카드 웹앱(PWA)입니다.

- 폴더(하위 폴더 가능) → 단원 → 카드 구조
- 학습 모드: 낱말카드 · 학습하기(맞힐 때까지 반복) · 테스트(O/X 자가채점) · 객관식 5지선다 · 매칭 · 복습
- 카드 형식: 기본(용어–정의) · 확인문제(증례 + 고정 보기 5개 + 해설) · 빈칸(본문 속 {{정답}})
- 별점 0~5 (카드·단원·폴더, 물려받기) · 카드 사진 여러 장 · 오답노트 · 통계
- 복습 일정: Anki의 FSRS 알고리즘 ([ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs), MIT)
- 모든 카드·사진·학습 기록은 각 기기의 브라우저 저장소에만 보관되며 서버로 전송되지 않습니다.
