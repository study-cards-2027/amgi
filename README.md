# 암기노트 v2.7

퀴즐렛 방식의 용어–정의 암기 카드 웹앱(PWA)입니다.

- 폴더(하위 폴더 가능) → 단원 → 카드 구조
- 학습 모드: 낱말카드 · 학습하기(맞힐 때까지 반복) · 테스트(O/X 자가채점) · 객관식 5지선다 · 매칭 · 복습
- 카드 형식: 기본(용어–정의) · 확인문제(증례 + 고정 보기 5개 또는 정답 돌려쓰기 + 해설) · 빈칸(본문 속 {{정답}})
- 카드 안 표(마크다운 표, 칸 안 빈칸 가능) · 사진이 든 카드팩(zip 또는 json + 사진 파일) 불러오기
- 빈칸 객관식: 변증만·처방만 골라 풀기(보기도 같은 종류, 같은 변증의 다른 처방은 숨김) · 폴더 국시 교시 순 정렬(1~4교시)
- 굵게(**글자**, 편집기 B 버튼, 굵게+밑줄로 표시) · 기본·사진 카드의 앞면 설명·뒷면 해설
- 표 합친 칸(`^` 위와, `<` 왼쪽과) · 빈칸 눌러 열고 닫기·모두 가리기(표 전체 화면 포함) · 틀린 카드 ✕ 표시
- 별점 0~5 (카드·단원·폴더, 물려받기) · 카드 사진 여러 장 · 오답노트 · ✕ 표시 · 통계
- 복습 일정: Anki의 FSRS 알고리즘 ([ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs), MIT)
- 모든 카드·사진·학습 기록은 각 기기의 브라우저 저장소에만 보관되며 서버로 전송되지 않습니다.
